article writing guide:
before writing each article decide the INPUTs then based on following input & rules etc write it:
══════════════════════════════
         🔧 INPUT
══════════════════════════════
TITLE           : [INSERT TITLE]
FOCUS KEYWORD   : [INSERT FOCUS KEYWORD]
LSI KEYWORDS    : [INSERT 8–10 LSI KEYWORDS]
AUDIENCE        : [WHO IS THIS FOR?]
COUNTRY         : Worldwide
WORD COUNT      : [e.g., 2000–2500]
CONTENT TYPE    : [How-To / Listicle / Comparison / Informational]
TONE            : Conversational

══════════════════════════════
       ✍️ WRITING RULES
══════════════════════════════
- Write like a real expert — natural, flowing, human
- Vary sentence length for rhythm and readability
- Short paragraphs (2–4 lines max)
- Smooth transitions between every section
- Bold only what truly matters
- Zero filler phrases:
  ✗ "In today's digital world"
  ✗ "It is important to note"
  ✗ "In conclusion, it is clear"
  ✗ Passive voice overuse

══════════════════════════════
       📐 STRUCTURE
══════════════════════════════
① [Meta Description] — 150–160 chars, keyword included
② H1 — Exact title
③ Intro — Hook + problem + promise, keyword in first 100 words
④ 5–7 H2 Sections — Each with H3s where needed, end each 
   with a smooth 1-line bridge to the next
⑤ Conclusion H2 — Key takeaways + soft CTA, no new info
⑥ FAQ H2 — 4–5 H3 questions, 2–4 sentence answers each

══════════════════════════════
        🔍 SEO RULES
══════════════════════════════
✔ Focus Keyword in: H1, intro, one H2, meta, conclusion
✔ LSI keywords spread naturally throughout
✔ Keyword density: 1–1.5%
✔ One real example or use case per article
✔ Every section must add unique value — no padding

══════════════════════════════
       🚫 NEVER DO
══════════════════════════════
✗ Start article with "I"
✗ Use em dashes (—) in body text
✗ Vague or repetitive conclusions
✗ One-line FAQ answers
✗ More than one exclamation mark total
✗ Recommend tools without explaining why
